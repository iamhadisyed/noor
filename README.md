# Kindo / Noor (نور) — Laravel backend

REST API for the Kindo Junior (child) and Kindo Parent apps: AAC need alerts via FCM, practice-session sync,
printable PECS PDFs, and Pro-tier AI pediatric reports (Groq pool → Gemini pool failover).

Requires PHP 8.2+. Built on Laravel 12 (Laravel 11 is end-of-life and has open security advisories).

## Setup
```bash
composer install
cp .env.example .env && php artisan key:generate
# set DB_*, MAIL_* (SMTP), SUPER_ADMIN_EMAILS, GROQ_API_KEYS="k1,k2,k3", GEMINI_API_KEYS="k1,k2,k3", FCM_PROJECT_ID
php artisan migrate --seed       # seeds stock AAC cards
php artisan storage:link
# place the Firebase service account at storage/app/firebase-service-account.json
php artisan test
```

## Shared hosting (GoDaddy cPanel)
`QUEUE_CONNECTION=database`, plus two cron jobs:
```
* * * * *   cd /home/USER/public_html && php artisan schedule:run >> /dev/null 2>&1
*/2 * * * * cd /home/USER/public_html && php artisan queue:work --stop-when-empty --tries=2 --timeout=60 >/dev/null 2>&1
```
Run `php artisan config:cache` in production; keys are read through `config/kindo.php`, never `env()` at runtime.

## API (`/api/v1`, Sanctum bearer token)
| Method | Path | Notes |
|---|---|---|
| POST | auth/code | email a 6-digit sign-in code (neutral answer, 60 s cooldown) |
| POST | auth/verify | exchange email + code for a bearer token; first use creates the account |
| GET/PATCH | me | profile, role, plan |
| GET/DELETE | me/sessions | list and revoke signed-in devices |
| POST | auth/logout | |
| GET | admin/* | super admin only (`SUPER_ADMIN_EMAILS`) |
| POST | devices | register FCM token |
| GET/POST | children | free: 1 profile, pro: 4 (402 beyond) |
| POST | child/alert | logs need + high-priority FCM push to parent devices |
| GET | children/{id}/needs · POST needs/{id}/acknowledge | live feed |
| GET/PATCH/DELETE | children/{id} | profile, **track** (standard or special) and **support profile**; delete removes all stored media |
| GET | task-types | the per-type picture and sound rules, shared by web and app |
| GET | lesson-templates | starter lessons for the standard and special tracks |
| GET/POST | children/{id}/lessons (+ `/from-template/{id}`) | free plan: 3 lessons per child |
| GET | aac-cards | stock cards plus your own (`custom: true`, with signed `icon_url` / `audio_url`) |
| POST/PATCH/DELETE | children/{id}/aac-cards · aac-cards/{id} | your own picture cards: multipart `english_label`, `urdu_label`, `category` (needs/food/emotions/activities), `icon`, optional `audio`; free plan 3 per child |
| POST | children/{id}/lessons/import | Pro: multipart `photo` (+ `language`, `week_number`) → draft lesson via Groq/Gemini vision; photo is not kept; 10 per hour |
| GET/PATCH/DELETE | lessons/{id} | DELETE archives |
| POST | lessons/{id}/publish · unpublish · duplicate | publish returns 422 with the exact missing pictures and sounds |
| POST/PATCH/DELETE | lessons/{id}/tasks · tasks/{id} · reorder | |
| POST/DELETE | tasks/{id}/media | `kind=image` (re-encoded to a 600 px JPEG) or `kind=audio` (≤150 KB, checked by content); stored privately, served by short-lived signed links |
| GET | children/{id}/insights/summary · daily · export.csv · report.pdf | parent reports: practice, accuracy, alerts, reply time, lessons (query `days`, `tz`) |
| GET/POST | needs/{id} · seen · acknowledge | alert status sent → seen → on_the_way, who replied, reply time |
| GET | admin/overview · usage · quality · alerts · ai-reports · health · audit | super admin reporting: aggregates only, no child names or media |
| GET/PATCH | admin/users | search accounts; suspend, restore, change plan (audited) |
| GET | aac-cards · pecs.pdf | free tier: 4 core cards |
| GET/POST | children/{id}/family | free: 2 cards; photo ≤300 KB, audio ≤150 KB |
| POST | children/{id}/sessions | offline sync of practice results + mistakes, plus optional `letters[]` (letter, attempts, successes, assisted, deviation) |
| GET | children/{id}/milestones · milestones/{key}/card.png | milestones reached, and a shareable 1080×1080 PNG card for one (query `lang=en|ur`, `name=0|1`) |
| GET | children/{id}/letters | per-letter tracing results: accuracy, guide use, drift, trend, status, focus letters (query `days`, `tz`) |
| POST/GET | children/{id}/reports, reports/latest | Pro only; generated by queued job |

Scope note: this repo contains the backend only. The Flutter/native apps from the spec are not included. The checklist for the people building them is in `docs/APP_HANDOFF.md`.

Urdu in the PECS PDF: DomPDF cannot shape Arabic script, so `App\Support\UrduShaper` joins letters and `UrduText` draws each label with GD/FreeType (needs the `gd` extension with FreeType) using Noto Naskh Arabic from `resources/fonts` (SIL OFL licence included).

## Web portal (`/portal`)
Parents and the super admin sign in at `https://YOUR-DOMAIN/portal/` with an email and a 6-digit code; it uses the same `/api/v1` as the app. Set in `.env`:
- `MAIL_MAILER`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM_ADDRESS` (SMTP from cPanel or a mail service) so codes can be sent
- `SUPER_ADMIN_EMAILS=you@example.com` (comma separated)
- `APP_URL` as the public https address (used in signed picture and sound links)
- `KINDO_OTP_COOLDOWN` seconds between codes (default 60)

Content review: the super admin's **Content review** page lists flagged lessons, lets them open any lesson (pictures and sounds included, audited), manage blocked words, and make accounts inactive from **Accounts**. The terms text lives in `config/legal.php` (draft: have it reviewed, and raise `version` to ask parents to accept again); the starter blocked-word list is `config/moderation.php`.

Family-card photos and voices are private (signed links only). On an installation that already has cards, run once after deploying: `php artisan kindo:privatize-media` (moves old public files to private storage, safe to repeat).

Games: practice earns play minutes and games unlock while there are minutes (see `docs/GAMES.md`). Set `APP_TIMEZONE` (for example `Asia/Karachi`) so "today" matches the family's day. After deploying run `php artisan migrate` and, on an existing install, `php artisan db:seed --class=GameItemSeeder`, then upload each animal's picture and sound in the admin **Game library** (the listening games open once 4 animals are complete).

Privacy: parents can download all their data and delete their account from Settings (`GET /api/v1/me/export`, `POST /me/delete-code` then `DELETE /me`). Deletion needs working email, since it asks for a code.

Billing: Pro is sold or given as one-time voucher codes (admin **Vouchers** page; parents enter them in Settings under Plan). The daily job `kindo:billing-daily` (scheduled 04:05) emails a warning three days before Pro ends and moves ended plans back to free. Buying inside the app stores is not built yet.
Backups: set `KINDO_BACKUP_PASSWORD` in `.env`; a nightly encrypted backup then runs by itself (`php artisan kindo:backup` by hand, `php artisan kindo:restore FILE --force` to restore). Read `docs/BACKUPS.md`, especially the part about keeping a copy off the server.

Browser tests: `tests/e2e/run.sh` (see `tests/e2e/README.md`).
