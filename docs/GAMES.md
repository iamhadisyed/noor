# Games and rewards

Games are a reward, not a distraction. Practice earns **play minutes**; a game can only be started while there are minutes to spend, and it stops when they run out. Everything below is an API the app and the portal share.

## 1. Earning (all numbers are per-child settings)

A practice session is uploaded with `POST /children/{id}/sessions` (as before). The response now carries a `reward`:

```json
{ "id": 91, "reward": { "earned": 8, "reasons": [{"reason":"good_score","minutes":5},{"reason":"improvement","minutes":3}], "balance_minutes": 14, "capped": false } }
```

| Reason | When | Default |
|---|---|---|
| `good_score` | accuracy at or above the bar | 70% (60% for a child on the special track) → 5 min |
| `improvement` | accuracy beats the child's own average of their last 5 sessions by 10 points (needs 3 earlier sessions in 14 days) | 3 min, even if below the usual bar |
| `streak` | practised today and the days before, N days in a row (once a day) | 3 days → 3 min |
| `effort` | a session below the bar, if "reward for trying" is on | off (on for the special track) → 2 min |
| `parent_bonus` | the parent adds minutes by hand | 1–60 min, audited |

Guards: a session needs at least 5 tries (3 on the special track) to earn anything; at most 30 minutes can be earned a day; at most 60 can be saved up. A retried upload (same `Idempotency-Key`, or the same session) can never pay twice, because each reward row is tied to the session id. "Today" follows `APP_TIMEZONE`, so set it (for Pakistan: `Asia/Karachi`).

## 2. Playing

```
GET  /games                                  catalog, and whether this install has the content each game needs
GET  /games/library                          icon names and the animals (signed picture and sound links) for the app to cache
GET  /children/{id}/rewards                  balance, rules, ledger, each game's state: unlocked | locked | switched off | needs content, level, plays
POST /children/{id}/games/{game}/start       {rounds?: 3-20}  → session id, level, allowed_seconds, rounds[]   (423 if locked, with a reason)
POST /game-sessions/{id}/finish              {rounds_played, correct, seconds_played} → minutes spent, balance, new level
```

- `423 Locked` carries `reason`: `no_minutes` (with `how_to_earn`), `switched_off`, or `no_content`.
- The app receives the **whole session at once**, answers included, so it plays offline and reports at the end. Rewards are earned by practice, never by game scores, so there is nothing to gain by peeking.
- Only the time actually played is spent (rounded up to the minute, capped at what was allowed). A game that is never reported spends nothing. Reporting twice changes nothing.
- **Adaptive difficulty** per child and game, levels 1 to 5: 85% or better moves up, below 50% moves down, otherwise stays. Sessions of fewer than 5 rounds do not change the level.
- Number of answer choices follows the child's support profile (2 to 4). "Odd one out" always shows at least 3.

## 3. The games

| Game | Category | What the child does |
|---|---|---|
| `count` | Maths | counts pictures, picks the number (1–3 up to 1–15) |
| `add_sub` | Maths | small sums with pictures: add to 5, to 10, take-away, up to 20 |
| `number_order` | Maths | fills the gap in a number line: by 1, 2, 5, 10, counting down |
| `animal_sound` | Listening | hears a sound, picks the animal (a roar → the lion) |
| `sound_guess` | Listening | sees the animal, picks the sound it makes |
| `memory_match` | Brain | flips cards to find pairs (2 up to 8 pairs) |
| `odd_one_out` | Brain | picks the one that does not belong |
| `pattern` | Brain | finishes a pattern (AB, AAB, ABC, ABB, ABBC) |

Round shapes are in `app/Services/GameEngine.php`; the tests check every game at every level and choice count (valid answers, no duplicate options, correct maths).

### More games (added later)

All of them are generated by the server with the same rules as above: the whole session at once, adaptive levels 1 to 5, the number of choices from the child's support profile, 423 reasons, and the same play-minute accounting. `GET /games` and `GET children/{id}/rewards` give each game a `for` list (`standard`, `special`) saying which kind of child it suits best; the apps put those first, but every game works for every child. `POST .../games/{game}/start` also accepts `language` (`en` or `ur`) for the games about letters and words.

| Game | Group | What the child does | Round shape |
|---|---|---|---|
| `first_letter` | Letters and words | sees a picture, picks the letter its name starts with | `icon`, `options` (letters), `answer_index` |
| `spell_picture` | Letters and words | sees a picture, **spells its name on the alphabet keyboard** | `icon`, `target`, `keyboard` (`english`/`urdu`), `first_letter_hint`; the app compares what was typed with `target` (no `options`) |
| `alphabet_gap` | Letters and words | fills the missing letter in a run of the alphabet | `sequence` (one `null`), `options`, `answer_index` |
| `opposites` | Letters and words | picks the opposite word | `word` {en, ur}, `options` (words), `answer_index` |
| `calendar` | Letters and words | which day or month comes after or before (months from level 4) | `given`, `relation`, `options` {en, ur}, `answer_index` |
| `colors` | Colours and groups | level 1 and 2: taps the named colour; later: names the colour shown | `mode` (`find`/`name`), `target`, `options` (colours with `hex`), `answer_index` |
| `which_group` | Colours and groups | "Which one is a fruit?" among pictures of different kinds | `group`, `options`, `answer_index` |
| `match_same` | Colours and groups | finds the picture identical to the one shown (very different choices at first, similar ones later) | `target`, `options`, `answer_index` |
| `more_less` | Maths | which group has the most (from level 2 sometimes the fewest) | `ask`, `options` {count, icon}, `answer_index` |
| `feelings` | Feelings | names the feeling of a face; later also finds the face for a feeling | `mode` (`name`/`face`), `target`, `options`, `answer_index` |
| `routine_order` | Daily routines | puts 2 to 5 steps of a routine (morning, bedtime, hand washing, a meal) in order | `routine`, `steps` (shuffled), `answer_order` (keys in the right order; no `options`) |

`GET /games/library` also lists the `feelings`, `colors` (with hex values) and `routines` the apps must draw.

### Calm activities

Not games: no score, no play minutes, never locked. `GET /activities` returns five (`breathing_bubble`, `five_senses`, `squeeze_release`, `slow_count`, `movement_break`), each with `kind`, bilingual `title` and `about`, `cycles` and `steps` of `{cue, seconds, text{en,ur}}`. A `cue` is `in` (grow), `hold`, `out` (shrink), `rest` or `do`. A child on a "no timers" profile taps to move to the next step. When one is finished the app may send `POST children/{id}/activities/{activity}/done {seconds}`; the parent sees counts in Reports ("Calm activities") and the data export.

### Games for ages 3 to 10 (11 more)

Every game now carries `age` = `[youngest, oldest]` in `GET games` and in the `games[]` of `GET children/{id}/rewards`; the apps show the games that fit the child's age first ("Made for you") and the rest under "More to try". Every game still works for every child. Same session rules as above.

| Game | Ages | What the child does | Round shape |
|---|---|---|---|
| `number_tap` | 3-5 | is shown a number, taps the group with that many | `number`, `options` {count, icon}, `answer_index` |
| `size_game` | 3-5 | taps the biggest or the smallest of the same picture | `ask`, `options` {key, `scale`}, `answer_index` |
| `word_to_picture` | 5-7 | reads a word, taps its picture | `word` {en, ur}, `options` (icons), `answer_index` |
| `last_letter` | 5-8 | picks the letter a picture's name ends with | `icon`, `options` (letters), `answer_index` |
| `bigger_number` | 5-8 | picks the bigger (later sometimes smaller) number, up to 9999 | `ask`, `options` (numbers), `answer_index` |
| `number_bonds` | 6-9 | finds the missing part: `3 + ? = 7` | `expression`, `total`, `a`, `options`, `answer_index` |
| `word_blank` | 6-9 | **guesses the missing letter** of a word with a picture hint | `pattern` (letters, one `null`), `icon`, `options` (letters), `answer_index` |
| `read_clock` | 7-10 | reads an analogue clock (hours, then halves, quarters, five minutes) | `hour`, `minute`, `options` ("3:45"), `answer_index` |
| `scramble` | 7-10 | **word puzzle**: taps jumbled letters into the right order | `mode: scramble`, `target`, `letters` (shuffled), `keyboard`, `icon`, `show_hint` |
| `hangman` | 7-10 | **guess the secret word** letter by letter on the alphabet keyboard; a wrong letter costs a heart, running out only shows the word, nobody "loses" | `mode: guess`, `target`, `max_misses`, `keyboard`, `icon`, `show_hint` |
| `times_table` | 8-10 | multiplies, with the sum drawn as groups of pictures when small | `expression` ("3 × 4"), `a`, `b`, `options`, `answer_index` |

`scramble` and `hangman` have no `options`: the app scores them with the same call as spelling (the typed or built word compared with `target`; an empty string for "the word was not found"). The core package tells the round kinds apart with `GameRunner.kindOf` (`scramble`, `guess`). Word games draw from the 25 shape/fruit/animal/vehicle/toy names plus about 45 more words (`config/games.php` `words`, each with a picture key the app can draw); in Urdu only words with an Urdu name that can be typed on the Urdu keyboard are used. Longer words at higher levels; the picture hint disappears at the top levels.

### More calm and movement activities

Six more (11 in all): `balloon_belly`, `bubble_blowing` (breathing), `animal_stretch`, `slow_simon` (movement), `body_scan`, `good_things` (for older children). Every activity now has `emoji` and `age` for the shelf.

## 4. Content that has to be supplied

- **Animal pictures and sounds.** The two listening games use the animal library. The 12 animal names are seeded (`php artisan db:seed --class=GameItemSeeder` on an existing install); the super admin uploads a picture and the sound each animal makes in **Game library**. An animal is used only when it has both, and the listening games open when at least 4 are ready. Use sounds you have the right to use (your own recordings, or public-domain / CC0 libraries) and keep them under 150 KB (about 3 to 5 seconds). No animal sounds are shipped with the code.
- **Icon artwork.** Counting, add and subtract, memory, odd-one-out and pattern use named icons (apple, ball, circle ...). The server sends only keys and names in English and Urdu (`GET /games/library`); the app draws them, so original artwork has to come from design.
- **Game screens** exist in `apps/kindo_junior` (shelf with colours and pictures, every round shape above, confetti for a right answer unless the child has quiet praise). Pictures are shapes, faces and emoji until final artwork is supplied (`apps/kindo_ui/lib/src/widgets/art.dart`).

## 5. Parent controls (portal **Rewards** page and the same API)
Rewards on or off, the bar for a good session, minutes per good session, bonus for improving, reward for trying, daily limit, longest single play, switching individual games off, and bonus minutes by hand. The balance is part of the child record, so it syncs to every device (`GET /sync`).
